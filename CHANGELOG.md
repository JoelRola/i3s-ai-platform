# Changelog

## 1.0.0 — I3S Platform V1

- Established qwen3.5:9b generation on A100 and qwen3-embedding:4b on P100.
- Added isolated I3S Toolbox document, image, OCR, archive, audio/video foundations.
- Added Prometheus, Grafana, Loki, Alloy, GPU metrics, and public-access watchdog.
- Hardened Toolbox archive extraction and preserved private-only service exposure.
- Added Git safety controls, CI validation, and a manual targeted-release process.

Known V1 limitation: normal-user Open WebUI model visibility requires an authenticated administrator to apply the prepared supported API/UI changes.
